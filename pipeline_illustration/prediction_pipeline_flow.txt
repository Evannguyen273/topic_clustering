PREDICTION SAFEGUARDS:
--------------------
1. Each tech center maintains its own "last_processed_timestamp" in registry.json
2. Registry is only updated after successful prediction (not before/during)
3. Failures don't update registry, so next run tries the same time window again
4. Prediction outputs are organized by date: tech_center/prediction/YYYYMMDD/
5. Each run creates its own stats file with information about successes/failures
