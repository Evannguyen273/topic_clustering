2. USER QUERY FLOW
------------------

    [User] → "Show me all high priority problems from last month"
       │
       ▼
    [Intent Classification] → "This is a data retrieval request with filters"
       │
       ▼
    [Entity Extraction] → "priority=high, timeframe=last month, table=Problems"
       │
       ▼
    [SQL Generation] → "SELECT * FROM stage.Problems 
                        WHERE Priority='High' 
                        AND CreatedDateTime >= DATEADD(month, -1, GETDATE())"
       │
       ▼
    [Database] → "Returns 42 rows of data"
       │
       ▼
    [Response] → "I found 42 high priority problems from last month. 
                  The most common category was Network Issues (15)..."
